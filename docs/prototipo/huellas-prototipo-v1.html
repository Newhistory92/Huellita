Cómo se calcula lo que ves

  1. Cada caso tiene su propio destino de cobro. Una donación para Luna nunca puede terminar contada en el caso de Mora.
  2. Cuando Mercado Pago confirma un pago, avisa al sitio. El sitio vuelve a preguntarle a Mercado Pago si ese pago existe y está aprobado, antes de contarlo.
  3. Si el mismo aviso llega dos veces, se cuenta una sola vez.
  4. Las transferencias por CBU no suman hasta que una persona del refugio las verifica contra el extracto bancario.
  5. Nadie puede editar el total. Solo se pueden agregar movimientos, y cada movimiento queda con autor, fecha y motivo.
  6. Un error se corrige con un ajuste visible, nunca borrando el historial.
